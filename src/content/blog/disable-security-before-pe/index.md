装系统、修引导、抢救数据，绕不开进 PE。而一搜「进 PE」，几乎每篇教程都会带一句
「记得先关掉安全防护」。

这句话本身没错，但它把四件完全不相干的事混成了一件：固件层的 Secure Boot、
磁盘加密、系统里的 Defender、以及第三方杀软。它们挡的位置不一样，处理方式也不一样，
后果更不一样——其中只有一个是「不关就进不去」，其余都是「进去了也干不成事」。

这篇文章按层拆开讲。如果你只想看结论，跳到第 7 节的决策表。

> [!核心] 结论先给
>
> - **只有 Secure Boot 会真的让你进不去 PE**（第 2 节）
> - **BitLocker 不挡启动，但会挡你的数据**，提前确认恢复密钥（第 3 节）
> - **杀软挡的是做启动盘那一步，不是进 PE**（第 4 节）
> - 装完一定要按第 8 节的清单改回去

## 开始之前，先看这几条

这篇是决策参考，不是操作步骤。按它的结论动手之前，先确认下面这些。

| 条件 | 具体要求 | 不满足会怎样 |
|---|---|---|
| 能进 BIOS | 开机按 Del / F2 能进固件设置 | 改不了 Secure Boot，也改不了启动顺序 |
| 知道 BitLocker 状态 | 已确认目标机器有没有开设备加密 | 一进 PE 就被要恢复密钥，原有数据可能打不开 |
| 恢复密钥在手 | 微软账户里能查到 48 位密钥 | 加密盘在 PE 里只能看不能读 |
| 有 PE 启动盘 | 手边已经做好一只 | 这篇讲的是进 PE 之前的事，盘得先有 |
| 有管理员权限 | 能改系统设置、能临时关杀软 | 关不掉 Defender / 第三方杀软 |
| 知道怎么改回去 | 拍下改前的原始设置 | 装完忘了恢复，机器长期裸奔 |

**这篇只解决「要不要关、关哪一层」，不教怎么进 PE。** 做盘和装系统的完整流程在
[Windows 系统安装教程](/blog/windows-install-tutorial)。

## 1. 四道关卡，各挡各的

| 层 | 由谁控制 | 挡的是什么 | 不处理会怎样 |
|---|---|---|---|
| Secure Boot | UEFI 固件 | 引导程序的数字签名 | 根本进不去 PE，开机直接跳回系统 |
| 快速启动 / 启动顺序 | UEFI 固件 | 按键进 BIOS 的时机 | 按不出启动菜单，但换成重启进设置可以绕 |
| BitLocker / 设备加密 | 系统 + TPM | 硬盘内容的解密 | 进得去 PE，看到盘但读不了数据 |
| Defender / 第三方杀软 | 操作系统或杀软 | 磁盘引导扇区的写入 | 进得去 PE，但做启动盘时引导写失败 |

关键区别在这里：**只有 Secure Boot 会让你进不去，其余三种你都能进 PE，只是进去之后干不了事。**
所以「关掉才能进 PE」严格来说只对 Secure Boot 成立。

## 2. Secure Boot：唯一真正拦路的一层

### 它在校验什么

Secure Boot 是 UEFI 规范里的一环，[微软 Secure Boot 文档](https://learn.microsoft.com/en-us/windows-hardware/design/device-experiences/oem-secure-boot) 有完整说明。开机的顺序大概是：

```
通电 → UEFI 固件 → 读取 ESP 分区的 bootx64.efi
                 → 检查这个文件的数字签名
                 → 签名可信才继续，否则停下
```

它校验的是**引导程序这个文件**，不是你硬盘里装了什么系统。微软维护一份受信任的证书列表，
Windows 自带的 `bootmgfw.efi` 在里面，Windows 安装程序的光盘和 U 盘也在里面——
因为那些都是微软签过名的。

### 什么样的 PE 会被拦

- 微PE 较新版本、以及基于官方 ADK 制作的 PE，通常带着有效签名，能过
- 自己用 WinPE 手工拼的、改过引导文件的、或者用了来路不明的启动盘，签名缺失或者过期，过不了
- 一些老版本的 PE 用的是已经吊销的证书，也会被拦

`Invalid Signature Detected`，或者直接黑屏一下回到原来的系统。
`Invalid Signature Detected`，或者直接黑屏一下，回到原来的系统。

还有一种是**能进 PE，但键盘鼠标全不响应**——个别 PE 在 Secure Boot 下驱动加载不全，
这种也算变相被拦。

### 怎么关

各家 BIOS 的叫法不一样，位置通常在 Security 或 Boot 选项卡下：

| 品牌 | 路径 |
|---|---|
| 华硕 | Security → Secure Boot → OS Type 改成 Other OS |
| 微星 | Settings → Security → Secure Boot → 设为 Disabled |
| 技嘉 | Boot → Secure Boot → Disabled |
| 联想 | Security → Secure Boot → Disabled |
| 戴尔 | Security → Secure Boot → Disable |
| 惠普 | Security → Secure Boot Configuration → 取消勾选 |

有些主板这项是灰的，得先做两件事：关掉 CSM（有的话），以及给 BIOS 设一个管理员密码。
惠普和部分联想机型就属于这种。

### 关了之后的风险

Secure Boot 防的是 bootkit 和 rootkit——那种在系统启动之前就加载、藏在内核之下的恶意程序。
关掉之后，这类东西可以改写引导层，常规杀软基本看不见。

所以它是**临时措施，不是长期状态**。装完系统就该开回去，尤其是要装 Win11 的机器——
Win11 把 Secure Boot 列为硬性要求，长期关着会影响后续的大版本升级。

## 3. BitLocker：不挡启动，挡你的数据

这一层经常被误认为「安全防护拦住了 PE」，其实它拦的不是启动，是你打开硬盘的那一刻。完整机制见 [BitLocker 官方文档](https://learn.microsoft.com/en-us/windows/security/operating-system-security/data-protection/bitlocker/)。

### 会看到什么

进 PE 打开「此电脑」，原来的 C 盘、D 盘上挂着一把锁的图标，双击提示需要输入密码或者恢复密钥。
用分区工具看，分区类型是 `BitLocker Encrypted`。

如果只是要装系统，直接格式化那块盘就行，不需要解密。但如果**盘里有要保留的数据**，
就绕不过恢复密钥。

### 恢复密钥在哪

按可能性从高到低：

1. **微软账户**：[account.microsoft.com/devices/recoverykey](https://account.microsoft.com/devices/recoverykey)
   ——24H2 之后自动加密的机器，密钥默认就托管在这里
2. **打印出来的纸**：第一次开启加密时，向导会问要不要打印
3. **U 盘或其它分区的 `.txt` 文件**：向导也提供「保存到文件」
4. **工作或学校账户**：加入域的机器由管理员保管
5. **`manage-bde -protectors -get C:`**：能进系统时在命令行里直接查，参数含义见 [manage-bde 命令文档](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/manage-bde)

48 位数字，分成 8 组。输进去就能解锁，不需要真的解密整块盘。

### 能进系统的话，先做这一步
如果机器本身还能启动，只是打算重装，那就不要在 PE 里处理密钥，先在系统里做完：
如果机器本身还能启动，只是打算重装，那就不要在 PE 里处理密钥，先在系统里做完：

```
manage-bde -status            看加密状态和保护器
manage-bde -protectors -disable C: -rebootcount 1
```

第二条是**挂起**加密：重启一次，这一次启动不校验密钥，密钥本身还在盘上。
适合「重启进 PE 装系统」这种一次性场景，比完整解密快得多。

想彻底关掉就换成：

```
manage-bde -off C:
```

解密是后台跑的，机械盘可能要几个小时，期间别断电、别强制关机。

### 最容易后悔的一种情况

> 硬盘加了密，没记密钥，直接把系统重装了。

结果不是「数据没了」这么简单——那块盘会一直处于锁定状态，换任何系统、任何工具都打不开，
除非还能找回那个 48 位恢复密钥。格式化是唯一出路。

所以重装前请务必确认一遍：**这台机器的硬盘，现在是不是加密状态**。
不确定就在系统里跑一次 `manage-bde -status`。

## 4. Defender 和第三方杀软：挡的是「做盘」，不是「进 PE」

这一层被误解得最厉害。杀软不会阻止你从 U 盘启动——它跑在 Windows 里，PE 启动的时候
它根本不在场。

它真正干扰的是**制作启动盘**和**PE 里操作硬盘**这两个阶段。

### 典型的拦截场景

- Rufus 往 U 盘写引导扇区，被判定为「引导区修改」，行为拦截
- 微PE 安装程序释放 PE 镜像，写 MBR 时被杀软中断
- Dism++ 直接改系统文件、注入驱动，被当成可疑行为
- 各类 PE 里自带的分区、密码、激活工具，直接报毒并隔离

表现是：Rufus 走到一半报错、写完了但 U 盘不能引导、微PE 提示「写入失败」、
Dism++ 释放到一半卡住。这些都不是软件坏了，是杀软在半路把操作掐了。

### 正确做法：临时关，不是卸载

**Windows 自带的 Defender：**

1. 打开「Windows 安全中心」→「病毒和威胁防护」
2. 「病毒和威胁防护设置」→「管理设置」
3. 把「实时保护」关掉

注意这一步经常关不掉，开关是灰的或者自动弹回——因为**篡改防护**在起作用：

4. 先回到「病毒和威胁防护设置」，找到「篡改防护」，关掉它，说明见 [篡改防护文档](https://learn.microsoft.com/en-us/defender-endpoint/prevent-changes-to-security-settings-with-tamper-protection)
5. 再回去关实时保护

实时保护关掉后，Windows 会在重启或一段时间后自动帮你打开，这正好是想要的行为——
做完盘就不用管了。

**第三方杀软（360、火绒、卡巴斯基、火绒等）：**

光关界面上的开关不算数，服务还在跑。正确做法是在托盘图标上右键，「退出」或者
「暂停防护」，有的还需要在设置里关掉「开机自启」，否则重启后它又回来了。

### 别忘了一件事
有些杀软会顺带把 Rufus 或者微PE 的主程序本身隔离掉。装完系统打开杀软，
去隔离区检查，把误杀的文件恢复并加入信任列表，否则下次做盘还要再来一遍。

## 5. 进不去 BIOS 或启动菜单

这跟安全防护没关系，但经常被归到同一类问题里。

开了「快速启动」（Fast Boot）的机器，POST 阶段被压缩到一两秒，按键的窗口一闪而过，
手感上就是「怎么按都进不去」。

三个办法：

- 在 Windows 里走「设置 → 系统 → 恢复 → 高级启动 → 立即重新启动」，
  再从菜单里选「UEFI 固件设置」或「使用设备」
- 关机状态下按厂商的专用键，比如联想的 Novo 小孔、部分机型的 `F12` 长按
- BIOS 里先关掉 Fast Boot，之后再按就正常了

顺带一提，「使用设备」这个入口本身就相当于一个简易启动菜单，能直接选 U 盘，
完全不用进 BIOS 改顺序。

## 6. 什么情况下什么都不用关

这部分值得单独说，因为大多数人是被网上的教程吓得关了一堆东西。

如果你满足下面全部条件，**直接装，一层防护都不用动**：

- 用 Rufus 把官方 ISO 写进 U 盘，或者用官方的 Windows 安装程序
- 硬盘没有开 BitLocker 或设备加密
- 机器本来就是 UEFI + GPT，Secure Boot 开着
- 没有装第三方杀软，或者装了但没报拦截

这时候整个流程是：插 U 盘 → 走启动菜单 → 装 → 完事。中间不需要碰任何安全设置。

真正需要动手的，是两种情况：**用的 PE 没有有效签名**，或者**硬盘加密了但要在 PE 里读数据**。

## 7. 决策表

| 你的情况 | Secure Boot | 杀软 | BitLocker |
|---|---|---|---|
| Rufus 直装官方 ISO，无加密 | 不用动 | 写入失败才临时关 | 不用动 |
| 微PE，开机报签名错误 | 关掉，装完开回 | 做盘时临时关 | 不用动 |
| 微PE，能进但盘上挂锁 | 不用动 | 不用动 | 用恢复密钥解锁 |
| 要保留旧盘数据，盘已加密 | 不用动 | 不用动 | 必须拿到恢复密钥 |
| 整盘重装，数据都不要 | 不用动 | 不用动 | 直接格式化，不用解密 |
| 装 Win11 且硬件不达标 | 用 Rufus 绕过检测 | 不用动 | 装完关掉自动加密 |

## 8. 关完之后，恢复清单

改过的东西记得改回来。这些是机器最后一道防线，忘了开回来，风险比装系统本身大得多。

- [ ] BIOS 里 Secure Boot 重新打开
- [ ] 篡改防护和实时保护重新打开
- [ ] 第三方杀软重新启动，确认托盘图标在
- [ ] 杀软隔离区里的误杀文件恢复并加白
- [ ] 启动顺序改回硬盘优先
- [ ] 设备加密确认状态：要么关掉，要么把恢复密钥存好
- [ ] 跑一次 Windows Update，把病毒库和补丁补齐

## 小结

能拦住你进 PE 的，只有 Secure Boot 一层；BitLocker 挡的是数据不是启动；
杀软挡的是做盘不是启动。把这三件事分清楚，就不会再被「进 PE 要关杀毒」这种说法带着
关一堆本来该开着的东西。
